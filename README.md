# CubiCore

**Un launcher de Minecraft para Windows enfocado en perfiles independientes, modding y una experiencia simple de usar.**

> CubiCore es un proyecto independiente y no está afiliado, respaldado ni patrocinado por Mojang Studios o Microsoft. Minecraft y sus marcas pertenecen a sus respectivos propietarios.

## Descargar

### Windows 10 / 11 · 64 bits

**Recomendado:** descarga `CubiCore-Setup-1.1.0.exe` desde la sección **Releases**.

El instalador te permite:

- Elegir la carpeta donde instalar CubiCore.
- Elegir otro disco, por ejemplo `D:\CubiCore`.
- Crear acceso directo en el escritorio.
- Crear acceso en el menú Inicio.
- Desinstalar CubiCore desde Windows como una aplicación normal.
- Conservar la ubicación elegida al actualizar el instalador.

CubiCore incluye su propio runtime para ejecutar el launcher, por lo que el usuario no necesita instalar Java para abrir CubiCore.

## Actualizaciones

CubiCore comprueba las nuevas versiones publicadas en GitHub Releases.

- **Stable:** versiones finales recomendadas.
- **Beta:** versiones de prueba y versiones finales más recientes.

Los usuarios también pueden usar **Watch → Custom → Releases** en GitHub para recibir notificaciones cuando se publica una nueva versión.

## Funciones

- Minecraft Vanilla.
- Forge.
- Fabric.
- Java 8 / 17 / 21 gestionado por CubiCore según la versión de Minecraft.
- Perfiles independientes.
- RAM automática o manual por perfil.
- CubiCore Lite.
- Mods desde Modrinth.
- Shaders.
- Resource Packs.
- Perfiles de rendimiento.
- Importación de perfiles y modpacks.
- Exportación de perfiles `.cubicore`.
- Copias de seguridad y restauración.
- Modo offline para usos compatibles.
- Actualizador automático con rollback.
- Canales Stable / Beta.
- Personalización de apariencia e idiomas.

## Datos de CubiCore

Los datos del launcher se almacenan en:

```text
%USERPROFILE%\.cubicorelauncher
```

Aquí se guardan las instancias, versiones, librerías, runtimes y otros datos administrados por CubiCore.

## Seguridad

Las cuentas, tokens y credenciales no se incluyen al exportar perfiles.

Si descubres un problema de seguridad, evita publicar credenciales, tokens o información privada en un Issue público.
