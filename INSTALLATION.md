# Instalación de CubiCore

## Instalador recomendado

1. Descarga `CubiCore-Setup-1.1.0.exe`.
2. Ejecuta el instalador.
3. Pulsa **Siguiente**.
4. Elige dónde instalar CubiCore.
5. Puedes usar la ubicación recomendada o pulsar **Examinar** y elegir otro disco.
6. Decide si quieres un acceso directo en el escritorio.
7. Pulsa **Instalar**.
8. Al finalizar, puedes abrir CubiCore directamente.

## ¿Dónde se instala?

La ubicación recomendada es una carpeta del usuario, para que CubiCore pueda actualizar sus propios archivos sin necesitar privilegios de administrador.

También puedes elegir, por ejemplo:

```text
D:\Aplicaciones\CubiCore
D:\Juegos\CubiCore
E:\CubiCore
```

## Datos del launcher

La aplicación y los datos de Minecraft son cosas separadas.

La aplicación puede estar en:

```text
D:\Aplicaciones\CubiCore
```

mientras que los datos administrados por CubiCore permanecen en:

```text
%USERPROFILE%\.cubicorelauncher
```

Esto permite actualizar o reinstalar la aplicación sin borrar automáticamente tus perfiles y mundos.

## Actualizaciones

No necesitas volver a descargar manualmente cada versión. CubiCore consulta GitHub Releases y puede descargar una actualización desde el propio launcher.
